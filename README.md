# LaterLeaf
A single point of entry for all the LaterLeaf components.

This project is a read-it-later app like Pocket, but with AI features such as, summaries, chat, research, and audio overviews.
Backend - https://github.com/NathanHannon/nst-laterleaf
Frontend - https://github.com/NathanHannon/rct-laterleaf
Browser Extension - https://github.com/NathanHannon/laterleaf-browser-extension
